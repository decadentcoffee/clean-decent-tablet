Test every screen

Everything here runs in safe mode (?safe): a pretend tablet, so every screen looks and moves as in a real run but nothing happens in the background. Nothing connects to a real one. Walk it starts the scenario at the beginning with a Next / Back bar at the bottom left. The other links jump straight to one screen, in the state a real run would leave it: the page runs the steps before it for you, so give it a few seconds.
